---
description: Запустить AI агента
---

Запустить AI агента из командной строки.

Выполните следующие шаги:

1. Убедитесь, что проект собран (запустите `/build` если нужно)
2. Запустите `go run ./cmd/agent` для запуска агента
3. Если переменная окружения `AGENT_API_KEY` не установлена, предупредите пользователя
4. Сообщите путь к файлу конфигурации и как его настроить
