---
description: Очистить скомпилированные бинарные файлы и временные файлы
---

Очистить скомпилированные бинарные файлы и временные файлы проекта Go.

Выполните следующие шаги:

1. Удалите файл `agent.exe` если существует
2. Запустите `go clean -cache` для очистки кеша Go
3. Запустите `go clean -testcache` для очистки кеша тестов
4. Сообщите об результате очистки
