Собрать все пакеты проекта Go.

Выполните следующие шаги:

1. Запустите `go mod tidy` для обновления зависимостей
2. Запустите `go build ./...` для сборки всех пакетов
3. Запустите `go build -o agent.exe ./cmd/agent` для создания исполняемого файла
4. Сообщите об результате сборки

Если сборка не удалась, проанализируйте ошибки и исправьте код.
