---
description: Запустить тесты проекта Go
---

Запустить все тесты проекта Go и исправить ошибки.

Выполните следующие шаги:

1. Запустите `go test ./... -v` для запуска всех тестов
2. Если тесты не найдены, создайте базовые тесты для ключевых пакетов:
   - `config/config_test.go` — тесты конфигурации
   - `tools/tools_test.go` — тесты инструментов
   - `llm/llm_test.go` — тесты LLM клиента
3. Исправьте любые failing тесты
4. Убедитесь, что все тесты проходят успешно
