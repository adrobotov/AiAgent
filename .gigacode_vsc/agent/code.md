Вы — агент для разработки Go-кода AI агента.

## О проекте

Это интерактивный CLI AI агент на Go с поддержкой инструментов (tools/functions calling) и OAuth аутентификацией.

### Структура проекта

```
AiAgent/
├── cmd/agent/        # Точка входа (CLI)
├── config/           # Конфигурация
├── llm/              # Клиент LLM API
├── auth/             # OAuth аутентификация
├── agent/            # Ядро агента
├── tools/            # Система инструментов
├── config.yaml       # Файл конфигурации
├── go.mod            # Модуль Go
└── README.md         # Документация
```

### Ключевые пакеты

- **`config`** — загрузка и парсинг YAML конфигурации, определение URL провайдеров
- **`auth`** — OAuth аутентификация с автоматическим обновлением токенов
- **`llm`** — клиент для GigaChat API с OAuth аутентификацией
- **`agent`** — ядро агента с циклом обработки сообщений
- **`tools`** — система инструментов с интерфейсом Tool

### Правила разработки

1. Следуйте существующим конвенциям Go
2. Используйте пакетные имена в нижнем регистре без подчеркиваний
3. Экспортируйте только необходимые идентификаторы
4. Добавляйте комментарии к экспортируемым функциям и типам
5. Обрабатывайте ошибки явно, не игнорируйте их
6. Тестируйте новые функции

### Работа с LLM

- Прямой HTTP-клиент для GigaChat API
- Конфигурация через `config.LLMConfig`

### Работа с инструментами

- Реализуйте новый инструмент как тип, реализующий интерфейс `tools.Tool`
- Зарегистрируйте инструмент в `tools.NewManager()`
- Инструменты поддерживают function calling через GigaChat API

### Работа с OAuth (GigaChat)

- Ключ авторизации хранится в `config.LLMConfig.AuthKey`
- Токен доступа получается через `auth.TokenManager`
- Токен действует 30 минут и обновляется автоматически
- OAuth endpoint: `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`
